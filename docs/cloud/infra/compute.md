## 要点提纲

### 1. 实例规格族的读法

- 命名规律：代际 + 类型（通用/计算/内存/大数据/异构）
- 关键参数：vCPU:内存比（1:2 / 1:4 / 1:8）、网络带宽、PPS、本地盘
- 选型口诀：先看内存比定族，再看带宽定规格，最后按代际买新不买旧

### 2. 计费与成本模型

- 包年包月 / 按量付费 / 抢占式（竞价）实例 / 节省计划 / 预留券
- 经验值：稳态负载包月 + 弹性部分按量，混用通常比单模式省 30%+
- 抢占式适合：无状态、可中断、批处理、CI/CD

### 3. 弹性伸缩

- 伸缩组 + 伸缩规则（目标追踪/定时/预测）
- 镜像与启动模板：弹性速度的真正瓶颈在"启动时间"
- 与负载均衡、K8s 节点池的联动

### 4. Serverless 的边界

- 函数计算适合：事件驱动、突发、空闲时间长的负载
- 不适合：长连接、大内存、对冷启动敏感的低延迟场景
- 中间形态：Serverless 容器（按 Pod 计费，免节点运维）

### 5. GPU 与异构计算

- GPU 实例的定位：从"图形渲染"到"AI 训练/推理"的主力
- 选型要点见 [GPU 选型与推理成本测算](/ai/inference/gpu-sizing)
