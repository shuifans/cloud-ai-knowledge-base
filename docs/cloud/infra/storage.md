## 要点提纲

### 1. 三类存储的边界

| 类型 | 代表 | 接口 | 典型场景 | 不适合 |
| --- | --- | --- | --- | --- |
| 块存储 | 云盘 | 挂载为设备 | 数据库、文件系统 | 共享读写 |
| 对象存储 | OSS | RESTful API | 图片/视频/备份/静态资源 | 频繁随机小写 |
| 文件存储 | NAS/CPFS | POSIX 挂载 | 共享文件、AI 训练数据集 | 超大吞吐（选 CPFS/并行文件系统） |

### 2. 块存储要点

- 性能等级：吞吐型 / 高性能 / 极速（IOPS 与延迟差 1-2 个数量级）
- 容量、性能、价格三者的关系：多数事故源于"买了容量但没买够 IOPS"
- 快照与克隆：备份、灾备、测试环境快速拉起的基础

### 3. 对象存储要点

- 概念模型：Bucket / Object / Prefix（没有真正的"目录"）
- 成本优化三板斧：生命周期规则、低频/归档分层、压缩与格式优化
- 静态网站托管 + CDN：最便宜的发布方式
- 数据处理：图片处理、事件通知（Object → 函数触发）

### 4. 备份与容灾

- 3-2-1 原则在云上的映射
- 跨区域复制（CRR）、版本控制、合规保留（WORM）
- 常见误区：只备份不演练，RTO 从未验证过

### 5. AI 时代的存储

- 训练数据集：高吞吐并行文件系统（CPFS 类）成为标配
- 模型权重分发：OSS + 缓存加速
- Checkpoint 写入风暴：存储带宽是训练集群的隐形瓶颈
