# 游戏行业术语表

本页按业务主题定位术语主文。同一缩写在不同公司或平台中可能采用不同口径，调研时应核对定义、单位、时间和负责团队。

## 公司、产品与设计

| 术语 | 简明解释与易混淆点 | 主文 |
| --- | --- | --- |
| Developer / 研发商 | 负责游戏研发；不必同时负责发行 | [产业链](/gaming/industry/company-models) |
| Publisher / 发行商 | 组织产品进入市场及相关商业工作；责任以合作范围为准 | [发行流程](/gaming/publishing/distribution-growth) |
| 自研自发 / 联合运营 | 描述业务责任组合，不能直接据此推断全部数据与资产归属 | [公司模式](/gaming/industry/company-models) |
| Producer / 制作人 | 协调产品、资源与交付；与 PM 的边界因团队而异 | [岗位](/gaming/organization/roles) |
| PM / 项目经理 | 组织排期、依赖、变更与问题跟踪 | [岗位](/gaming/organization/roles) |
| TA / Technical Artist | 技术美术，连接美术目标、工具与运行约束 | [资产生产](/gaming/production/asset-pipeline) |
| GDD / 游戏设计文档 | 表达体验目标和规则，可与原型、配置共同使用 | [策划交付](/gaming/design/planning-deliverables) |
| Core Loop / 核心循环 | 玩家重复经历的行动、反馈和选择 | [玩法设计](/gaming/design/gameplay-economy) |
| Source / Sink | 经济资源的产出来源与消耗出口；转移不一定改变总量 | [经济系统](/gaming/design/gameplay-economy) |
| Prototype / 原型 | 验证特定假设的可操作样例 | [生命周期](/gaming/production/lifecycle) |
| Vertical Slice / 垂直切片 | 覆盖代表性体验与制作环节的样例，范围由项目约定 | [生命周期](/gaming/production/lifecycle) |
| Alpha / Beta / 首测 | 阶段或测试标签，必须附项目自身的验收定义 | [生命周期](/gaming/production/lifecycle) |

## 生产与运行

| 术语 | 简明解释与易混淆点 | 主文 |
| --- | --- | --- |
| DCC | 数字内容创作工具，如模型或动画制作工具 | [资产生产](/gaming/production/asset-pipeline) |
| Asset Pipeline / 资产流水线 | 从源内容到运行资源的转换、校验与交接 | [资产生产](/gaming/production/asset-pipeline) |
| LOD | 细节层次，按条件使用不同细节表示 | [资产生产](/gaming/production/asset-pipeline) |
| Build / 构建制品 | 由确定输入产生的交付结果，不等于源码版本本身 | [版本发布](/gaming/production/version-release) |
| 热更新 | 特定的增量或运行内容更新路径，不自动免除平台与兼容要求 | [版本发布](/gaming/production/version-release) |
| Authoritative State / 权威状态 | 由指定可信节点裁决的状态 | [业务系统](/gaming/systems/cloud-workloads) |
| Matchmaking / 匹配 | 按地区、玩法、技能等约束组织玩家会话 | [云需求](/gaming/systems/cloud-workloads) |
| LiveOps / 长线运营 | 围绕内容、活动、配置和反馈持续运营产品 | [长线运营](/gaming/operations/liveops-player-service) |
| 合服 | 涉及角色、社交、排名与权益规则的业务迁移 | [长线运营](/gaming/operations/liveops-player-service) |
| LQA | 本地化语言质量验证，需要与游戏内功能测试结合 | [本地化](/gaming/globalization/localization-governance) |
| 云游戏 | 远端渲染与流媒体交互，不等同于普通游戏后端上云 | [云需求](/gaming/systems/cloud-workloads) |

## 商业化、数据与验证

| 术语 | 简明解释与易混淆点 | 主文 |
| --- | --- | --- |
| IAP / IAA | 内购 / 广告变现，可以并存 | [商业模式](/gaming/industry/company-models) |
| DLC | 追加可下载内容，需明确本体依赖与权益 | [商业模式](/gaming/industry/company-models) |
| UA / 用户获取、买量 | 用户获取可含自然与付费来源；买量强调付费推广 | [发行增长](/gaming/publishing/distribution-growth) |
| Attribution / 归因 | 按规则关联来源与转化，不直接证明因果增量 | [归因边界](/gaming/publishing/distribution-growth) |
| Cohort / 群组 | 按共同条件划定用户，如同日首次启动用户 | [指标](/gaming/analytics/metrics) |
| DAU / WAU / MAU | 给定日、周、月窗口内的去重活跃用户 | [指标](/gaming/analytics/metrics) |
| CCU / PCU | 同时在线 / 期间峰值同时在线，需要定义采样与在线状态 | [指标](/gaming/analytics/metrics) |
| D1 / D7 / D30 留存 | 某新增群组在约定第 N 日的回访比例 | [指标](/gaming/analytics/metrics) |
| ARPU / ARPPU / ARPDAU | 每用户 / 每付费用户 / 每日活跃用户平均收入 | [指标](/gaming/analytics/metrics) |
| CPI / eCPM | 每归因安装费用 / 每千次广告展示收益 | [指标](/gaming/analytics/metrics) |
| ROAS | 约定归因收入与广告支出的比值，不是利润率 | [指标](/gaming/analytics/metrics) |
| LTV | 用户生命周期价值，需区分已观测窗口与长期预测 | [指标](/gaming/analytics/metrics) |
| 流水 / 收入 / 利润 | 不同业务与财务概念，金额范围和确认规则必须分别核对 | [公司模式](/gaming/industry/company-models) |
| PoC / 概念验证 | 在指定条件下验证问题，不等于生产验收 | [业务调研](/gaming/reference/discovery) |
