# 关于本站

本站是一个持续更新的云计算与人工智能技术知识库，目标是把分散的公开资料、技术原理与工程方法整理成一套**有结构、可检索、可核验、可持续演进**的知识体系。

## 内容声明

::: info 内容边界
本站内容遵循两条原则：

1. **一手来源优先**：技术概念、产品能力与版本状态优先以官方文档、原始论文和项目仓库为准；
2. **事实与建议分层**：可核验事实标注来源，工程建议标注适用条件，不用个人履历为观点背书；
3. **不包含个人与客户信息**：不披露作者履历、客户名称、内部系统或未公开数据。
:::
