# 关于本站

一个持续更新的个人知识库，作者是从业十余年的云解决方案架构师，完整经历了 **移动互联网 → 直播 → 区块链 → 元宇宙 → AI 大模型** 五个技术周期，长期在阿里云生态从事云计算与 AI 相关的解决方案设计与落地。

建站的目的只有一个：把散落在项目笔记、培训材料和脑子里的知识，整理成一套**有结构、可检索、可持续演进**的个人知识体系。

## 内容声明

::: info 内容边界
本站内容遵循两条原则：

1. **公开知识为准**：技术概念、架构原理均以官方公开文档与行业共识为基础，涉及阿里云产品处均可在官方文档中交叉验证；
2. **实践内容脱敏**：个人项目经验以行业化、场景化的方式泛化表述，不涉及任何客户名称、内部系统或未公开数据。
:::
