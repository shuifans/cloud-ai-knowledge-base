# 软件研发术语与查询索引

> 如果你只记得一个术语、工具名或遇到的场景，可以从这里找到解释与主文。索引提供简明定位，详细机制、实践和失败模式由对应文章承担。

## 三种查找方式

| 已知信息 | 入口 | 如何使用 |
| --- | --- | --- |
| 听到“仓库”“运行时”“锁文件”等陌生词 | [术语索引](/software/reference/terms) | 先看一句话解释和易混概念，再进入主文 |
| 正在接管项目、明确范围或检查 AI 改动 | [场景索引](/software/reference/scenarios) | 按要完成的任务选择阅读和核查顺序 |
| 只知道 Git、Node.js、npm 等技术名称 | [技术与工具索引](/software/reference/technologies-tools) | 区分它的职责，结合主文和官方资料查阅 |

这些入口共用全站搜索、导航与摘要，不建立另一套重复正文。主文覆盖 16 章项目导览和 17 个专业子域；按名称搜索时也可用英文缩写，结果中的“软件研发”筛选帮助缩小范围。概念可能跨领域，索引优先链接负责核心机制的文章，再由主文连接云和 AI 专题。
