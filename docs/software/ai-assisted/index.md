# AI 辅助研发与 Agent 工程

> 将 AI 纳入需求、受限执行与验证。本域面向AI 编程使用者及研发团队，每篇专题均可独立查阅；先从具体问题进入，再按需要补齐机制和工程边界。

## 范围与相邻领域

关注使用 AI 构造和维护软件时的任务、上下文、权限与验证。开发 AI 产品的模型、检索和 Agent 原理由 AI 领域解释；工具产品功能和模型价格须按具体版本另行核实。
