## 要点提纲

### 1. VPC 规划（上云第一步）

- CIDR 规划原则：预留扩展、避免与线下/其他云冲突、环境隔离靠 VPC 而不是子网
- 典型结构：生产 / 预发 / 测试三 VPC，DMZ / 应用 / 数据三层子网
- 路由与对等连接：同地域互通免费优先，跨地域用云企业网类骨干

### 2. 负载均衡

- 四七层分工：四层（高吞吐、协议透传）、七层（路由、证书、灰度）
- 健康检查与会话保持的正确姿势
- 常见坑：后端长连接空闲超时不一致导致 502；客户端源地址透传需求

### 3. 内容分发与边缘

- CDN 适用判断：静态占比、命中率、回源成本
- 全站加速 / 边缘计算的趋势：从"缓存"到"边缘运行时"
- 大文件分发：P2P 分发 + CDN 混用

### 4. 混合云互联

- 专线：延迟稳、带宽贵，适合长期稳定流量
- VPN：快速上线、加密开销，适合临时/备份链路
- 设计原则：双通道冗余（专线 + VPN 兜底），路由主备明确

### 5. 全球与多地域

- 全球加速类产品的本质：用骨干网替代公网，买的是"稳定延迟"
- 多地域架构的先决条件：数据同步方案先于网络方案确定
