# 短视频时代（约 2018–2021）

::: warning 🚧 本文是提纲页
正文整理中。这是 [技术编年史](/chronicle/) 的第六浪——被忽略的接棒者。
:::

## 时代的命题

直播教会行业"实时"，短视频教会行业"规模"：当内容消费从"看一场"变成"无限刷"，技术命题变成了**海量媒体的成本工程 + 推荐系统的规模化**——算法第一次成为基础设施级的存在。

## 要点提纲

### 技术栈记忆

- **内容管线**：上传 → 转码矩阵（多档位）→ 多级分发；"窄带高清"类智能编码成为成本生命线
- **推荐系统**：召回/粗排/精排/重排四段式流水线、特征平台、实时特征流（Kafka + Flink）、大规模 A/B 实验基建
- **消费端体验**：无限下滑、预加载策略、秒开率与首帧优化——端侧体验指标第一次由"算法+工程"共同定义

### 一线亲历的典型场景

- 存储账单的指数曲线：内容只进不出，PB 级对象存储 + 冷热分层 + 生命周期规则成为标配动作
- 转码成本战争：GPU 转码集群的利用率优化，编码档位与带宽的联动账
- 推荐驱动的系统架构：在线推理的延迟预算（几十毫秒级）倒逼特征服务与模型服务的工程化——**"模型即服务"的运维范式，其实是在这一浪成熟的**

### 兴衰逻辑

- 为什么兴起：移动终端成熟 + 推荐算法跨过可用性门槛 + 创作工具平民化，三要素齐备
- 为什么"看不见它退潮"：**短视频没有退潮，它变成了背景板**。当一种技术彻底融入日常，它就从"浪潮"变成了"环境"——这也是它长期缺席各类技术编年史的原因
- 留下了什么：推荐基础设施（所有 App 的标配）、海量媒体成本工程、视频云产品线的完整形态

### 对今天的启示

- **成本工程的传承**：当年为转码和带宽做的每一分优化，方法论正原样复用在推理算力上——token 成本优化的很多套路，在转码成本优化里都有原型
- **算法基础设施化的第一次预演**：推荐系统教会行业"如何把模型变成 7×24 的在线服务"，这正是大模型应用栈的直接前身
