# 元宇宙时代（约 2021–2022）

::: warning 🚧 本文是提纲页
正文整理中。这是 [技术编年史](/chronicle/) 的第四浪。
:::

## 时代的命题

3D 实时渲染、数字孪生、云游戏——**GPU 算力第一次从"辅助角色"变成"主角"**。这一浪很短，但它为 AI 时代完成了一次关键的基础设施预演。

## 要点提纲

### 技术栈记忆

- 云渲染 / 云游戏：像素流化（Pixel Streaming）+ 边缘节点部署
- 数字孪生：GIS + BIM + 实时数据，城市级三维场景
- GPU 云主机开始被认真研究：显卡型号、虚拟化（vGPU）、分时复用

### 一线亲历的典型场景

- 云展厅/虚拟发布会：疫情催化，渲染农场临时扩容的调度难题
- 工业数字孪生：数据接入比三维渲染难十倍
- 云游戏试水：延迟预算只有 100ms，网络与渲染的联合优化

### 兴衰逻辑

- 为什么兴起：巨头叙事 + 疫情线上化惯性 + GPU 供给改善
- 为什么退潮：内容生产跟不上（UGC 工具未成熟）、体验断层（头显笨重）、商业模式不清
- 留下了什么：**GPU 供给链与调度能力**、实时渲染基础设施、三维内容管线

### 对今天的启示

- 元宇宙是 AI 时代的前传：没有这一浪攒下的 GPU 供给与调度经验，大模型训练集群的扩张会更艰难
- 交互形态的成熟需要"内容飞轮"：技术就绪不等于生态就绪——这个教训同样适用于今天的 AI 应用
