# 移动互联网时代（约 2013–2015）

::: warning 🚧 本文是提纲页
正文整理中。这是 [技术编年史](/chronicle/) 的第一浪。
:::

## 时代的命题

智能手机普及 + 3G/4G 网络，让"应用"第一次直接触达每个消费者。业务爆发速度第一次超过了自建机房的扩容速度——**"上云"从选择题变成了必答题**。

## 要点提纲

### 技术栈记忆

- 应用：原生 App 双端开发，后端 LAMP/Java 单体起步
- 基础设施：从物理机房托管到第一批公有云主机
- 标志性能力：弹性伸缩开始被真正需要（运营活动秒级流量洪峰）

### 一线亲历的典型场景

- App 上线即峰值：推广带来的不可预测流量，逼出了"弹性"意识
- 第一次把数据库搬上云：备份、容灾、安全的信任建立过程
- 运营活动压测文化的形成：容量评估从拍脑袋到数据驱动

### 兴衰逻辑

- 为什么兴起：终端 + 网络 + 资本三要素共振，创业公司没有时间自建
- 留下了什么：云成为默认选项；DevOps、弹性、按量付费的心智奠基
- 为什么让位：流量红利见顶，竞争焦点从"有没有 App"转向"体验与内容形态"

### 对今天的启示

- 每一浪的起点都是"基础设施跟不上业务增速"
- 上云的正确姿势从未改变：先非核心、后核心，先可逆、后不可逆
