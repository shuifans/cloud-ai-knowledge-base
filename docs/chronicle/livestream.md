# 直播时代（约 2016–2018）

::: warning 🚧 本文是提纲页
正文整理中。这是 [技术编年史](/chronicle/) 的第二浪。
:::

## 时代的命题

"千播大战"把实时音视频推上主舞台。技术命题从"扛住流量"升级为"扛住流量且要实时、要便宜"——**CDN、转码、弱网对抗成为核心竞争力**。

## 要点提纲

### 技术栈记忆

- 推流/拉流协议：RTMP、HLS、FLV，以及低延迟的探索（RTC 化）
- CDN 成为基础设施：从静态加速到动态流媒体分发，调度与回源策略
- 转码集群：GPU/FPGA 转码的成本账第一次被认真计算

### 一线亲历的典型场景

- 头部主播开播 = 区域性流量洪峰：弹性调度与带宽预案
- 卡顿率作为北极星指标：首屏时间、卡顿率、码率自适应的体验三角
- 带宽成本战争：峰值带宽采购、闲置复用、动态转码档位

### 兴衰逻辑

- 为什么兴起：4G 资费下降 + 移动流量爆发 + 内容形态升级
- 留下了什么：实时音视频技术栈（后来滋养了视频会议与云游戏）；CDN 价格战打出的普惠分发能力
- 为什么让位：行业出清、监管趋严；短视频以更轻的形态接棒注意力

### 对今天的启示

- 成本结构决定商业模式：直播教会行业"带宽即成本"，正如今天"token 即成本"
- 实时体验的优化永远在"质量—延迟—成本"三角里做取舍
