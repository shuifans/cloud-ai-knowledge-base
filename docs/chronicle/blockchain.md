# 区块链时代（约 2017–2019）

::: warning 🚧 本文是提纲页
正文整理中。这是 [技术编年史](/chronicle/) 的第三浪。
:::

## 时代的命题

分布式系统的一次"再探索"：当多方互不信任时，如何用技术替代中介。技术本身在进步，但多数项目死于"用错了锤子"——**这是最有教育意义的一浪**。

## 要点提纲

### 技术栈记忆

- 共识算法：PoW、PBFT 及其变体；性能与去中心化程度的权衡
- 联盟链平台：Hyperledger 系与国内自研链，BaaS（区块链即服务）一度是云厂商标配产品
- 周边设施：链上存储限制催生"链上存证 + 链下存储"模式
- 存储链与挖矿技术生态（当年的持续跟踪方向）：IPFS/FileCoin 的分布式存储激励、Swarm 的以太坊生态存储、Chia 的"空间证明"——如今回看，它们是"用经济激励组织分布式资源"这一思路的大规模实验场，其调度与存储工程经验与今天的算力网络遥相呼应

### 一线亲历的典型场景

- 供应链金融溯源：最早跑通的务实场景（存证 > 支付）
- 司法存证与版权登记：哈希上证的真实需求
- 大量"为链而链"的 POC：中心化数据库完全够用的场景被硬套上链

### 兴衰逻辑

- 为什么兴起：比特币的财富效应带动技术出圈，"信任"叙事契合 B 端需求
- 留下了什么：分布式一致性工程的普及；可验证计算、存证类产品的真实市场
- 为什么让位：金融场景强监管、投机退潮；技术热度让位于可验证的 ROI

### 对今天的启示

- **技术泡沫的识别框架**：看"不用这项技术会怎样"——答案是"也没怎样"的场景终将退潮
- 潮水退去后留下的都是基础设施：正如区块链留下的一致性工程经验，正在被 AI 时代复用（可验证性、审计）
